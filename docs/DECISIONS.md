### P0-T1 verification notes

- Both native input files feed generation: `NativeGenerationProof` calls `GetForegroundWindow` from Input and `GetWindowRect` from Window in one compiled method. Neither file duplicates the other API.
- Analyzer negative probe: temporarily append `SendInput` to Input/NativeMethods.txt and add a source method outside ActionGate.cs calling `global::Windows.Win32.PInvoke.SendInput(0, null, 0)` in an unsafe context. `dotnet build src/ExileSight.Platform.Windows -warnaserror` exits 1 with **RS0030 at the probe call**. Moving that probe to Input/ActionGate.cs with its file-local pragma exits 0. Both temporary sources and the additional native entry were removed afterward; no input was executed.
- Documentation IDs were extracted with `dotnet build src/ExileSight.Platform.Windows -p:GenerateDocumentationFile=true -p:NoWarn=CS1591` while temporarily requesting the banned APIs. CsWin32's default wideCharOnly normalizes PostMessageW/SendMessageW to unsuffixed names; explicit A/W entries cover alternate settings too.
- Analyzer format: [official BannedApiAnalyzers documentation](https://github.com/dotnet/roslyn/blob/main/src/RoslynAnalyzers/Microsoft.CodeAnalysis.BannedApiAnalyzers/BannedApiAnalyzers.Help.md). Generator settings: [official CsWin32 schema](https://github.com/microsoft/CsWin32/blob/main/src/Microsoft.Windows.CsWin32/settings.schema.json).
