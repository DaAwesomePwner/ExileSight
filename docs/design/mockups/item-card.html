IN GAME · OMNI-KEY OVER AN ITEM

Item card

Answers “is this worth a second look?” in one glance, and adds only what the game’s own tooltip hides. It never reprints mod text.

1
Verdict. Hits against your highlight rules for this item class: wanted in teal ◆, unwanted in orange ✕.
2
Slots and base. Prefix and suffix pips (hollow = open, craftable) and the defence base percentile.
3
Mod rows. Short label, tier, roll position and the ilvl that tier needs. Same order as the game tooltip, so row 3 is line 3.
4
Compare. Deltas against the item you set as equipped in this slot. Stats we can’t compute are left out, never guessed.

PLACEMENT
Cursor is right of centre, so the game puts its tooltip to the left. The card opens to the right, top-aligned with the cursor, clamped inside the client. Click-through; moving the mouse or pressing Esc closes it, as today.
Sample values for illustration. Short mod labels (“+ max ES”) need a new label table keyed by stat ID; everything else comes from data the item-info feature already computes.
