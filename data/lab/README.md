# Updating Lab information
Edit info.txt when a PoE 1 patch changes trials or mechanics. Verify location names and unlock requirements against current game information, then build and inspect the panel on Windows. This hand-authored text is bundled as data/lab/info.txt; it is not downloaded at runtime.

Daily maps are exclusively user imports. Reset assumption: 00:00 UTC (LabLayout.ResetUtc). Rooms retain file order; the first room is treated as the entrance. No upstream schema, presets, or fixtures are bundled.
